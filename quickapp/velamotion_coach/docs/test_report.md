# VelaMotion Coach 测试与缺陷修复报告

更新时间：2026-08-10

## 1. 最终结论

本轮先修复 Android/运行时单位错配、真机假数据与采样率、GYRO 缺失处理、停止与诊断冲突四组问题，并在此基础上把界面收敛为“首页、教练、时间线、同步复盘”四个顶层页面。核心回归覆盖以下契约：

- 真实 ACC 只在两个有效回调之间插值，不把最后一帧保持到未来；断流进入 stale，恢复后从新帧重锚且不回填缺口。
- 缺少 ACC/GYRO 任一六轴能力时，真机训练在引擎、健康订阅和传感器流启动前阻断，也不会保存记录。
- 训练期间诊断被阻断，诊断期间训练被阻断；所有页面都保留即时“停止训练”入口。
- TRL 保留基线的 7 点居中均值、5 点居中中值和 Viterbi 当前帧语义，只重算受影响尾部并使用 32 窗口固定滞后，避免长会话每帧扫描完整历史。
- 单位边界只在适配层转换；真机数据固定落在 16Hz 网格，非法帧、首帧超时和断流均不会伪造样本。
- 同步成功不能伪装成精确结果；只有规范入站信封声明完整使用 3s/5s/8s 三尺度时，才进入“手机精确复盘”。
- 动画由单一截止时间调度器管理，页面隐藏只暂停特效而不停止采集/推理；销毁才释放提供器，且异步回调不能复活定时器。

## 2. 重复截图问题根因

该问题不是单一 UI Bug，而是部署、进程、导航和渲染时序叠加导致：

1. Release 安装命令返回时，设备端应用目录可能尚未完成替换，截图脚本会启动旧 bundle。
2. 旧 QuickJS 应用进程未完全退出，重新启动后仍可能保留旧页面状态。
3. NuttX shell 某些失败命令仍返回退出码 0，错误文本曾被误当成 bundle 内容参与哈希判断。
4. ADB 可能显示连接但设备已进入模拟器 `poll` 忙循环，形成“假在线”。
5. gRPC 截图/点击需要正确鉴权；失败或落到错误前台时会连续取得同一 framebuffer。
6. 训练期间周期性保活点击会在慢推理时堆积，造成停止训练和翻页事件延迟。
7. 算法日志已切换到“跑步”后，QuickJS 页面渲染仍有延迟，立即截图会截到上一帧“无活动”。

## 3. 已实施修复

- 部署后核对本地 Release 与设备端 bundle SHA-256，只有一致时才继续。
- 对 `am stop`、`pm uninstall` 和安装后的设备状态增加重试与后置验证。
- 过滤 NuttX shell 错误文本，避免把错误输出当作有效 bundle。
- 检查目标 QuickJS 进程，避免旧进程和旧页面污染截图。
- 修复 gRPC 截图鉴权，并对前台页面、页面 QA 标记和截图质量做联合判断。
- 默认关闭训练保活点击，仅在 `DEMO_KEEPALIVE_INPUT=1` 时显式启用。
- 修正首页开始/停止按钮检测区域，覆盖 480 px 画布中的真实按钮范围。
- clean Release 冷启动时最多等待 30 秒，直到出现有效四页 QA 标记，避免“进程已存在但 QuickJS 尚未 onShow”被误判为导航失败。
- 动态首页使用双重门禁：
  - 日志必须出现 `VMC_DYNAMIC_UI activity=跑步`；
  - 首页活动区域必须检测到至少 8 个接近 `#F97316` 的像素。
- 采集后检查唯一哈希、空白帧、表盘帧、边缘黑层和相邻页面结构相似度。
- 真实传感器帧改为严格有限 `number` 校验，禁止空值、字符串和布尔值被转换为零值后当作真数据。
- 首帧超时后安全退订；已收到真帧后的断流保持订阅等待恢复，状态回调仅在生命周期转换时触发。
- 真机六轴门禁用生产页面方法的依赖桩执行验证，不再只检查源码字符串顺序。
- 教练页折叠/展开条件容器显式设为 376 px 纵向布局，修复 openVela 默认横向 flex 导致活动卡、六条概率和建议挤成一行的问题。

## 6. 仍需明确的技术边界

- 官方模拟器镜像当前没有可注入的步数传感器目标；ACC、GYRO、心率采用官方 Mock，步数采用应用内场景 Mock。
- 小米手表/手环真机上的 `service.health`、真实 ACC/GYRO、振动触感、不同屏幕尺寸和功耗尚未完成验证；当前公开 JS API 未提供 GYRO，完整真机训练会被明确阻断且不会保存。
- 当前比赛闭环默认使用 `tiny_classifier` 轻量特征分类器；原论文 CNN-BiLSTM/ensemble 资产已盘点，但完整原生/量化推理仍需目标设备推理桥或官方 NN SDK。
- 手机同步已实现 `@system.interconnect` 接口与降级诊断，但仍需真实手机和手表配对环境做端到端验收。

这些边界不会影响模拟器演示闭环，但提交材料中不得写成已经完成真机验证或论文模型完全等价迁移。
